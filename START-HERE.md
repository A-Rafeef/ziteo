# Start here

Read [docs/PRODUCTION-SETUP.md](docs/PRODUCTION-SETUP.md) for the current activation status, phased rollout and remaining account setup.

The project now runs with `npm run dev` and builds for Vercel with `npm run build`. Earlier Sites/Vinext/D1 deployment commands do not apply to this branch.

Copy `.env.example` to `.env.local`, populate credentials locally, and run `npm run env:check`. Do not paste secrets into chat or commit them.
